# Code of conduct

We want this project to be a welcoming place to work on hard problems.

- Be respectful and assume good intent. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks or sexualised language, in any project space.
- Keep discussion on topic and help newcomers find their way.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability is fine for this too). Maintainers may remove content and contributors who break these rules.

This code is adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
