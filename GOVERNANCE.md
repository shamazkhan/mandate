# Governance

Mandate is an open protocol with a reference implementation. The aim is a standard that brokers, platforms and agent builders can all rely on without depending on any one company.

## Today (draft 0.x)

- **Editor:** Shamaz Khan. The editor merges changes to the specification and the code, and publishes releases.
- Decisions are made in public issues and pull requests. Specification changes stay open for comment for at least 7 days before merging, unless they fix a security problem.
- Anyone can propose changes. Rough consensus among people implementing the protocol carries more weight than volume of comment.

## Towards 1.0 of the protocol

- An **implementers' council** of brokers, platforms and agent builders who run Mandate in production will be formed. Council members review specification changes and vote on contested ones.
- Once there are at least three independent verifier implementations, the specification will move to a neutral home (a foundation or standards body) under the same open licences.

## Trademarks and names

"Mandate" is a working name for the protocol and may change before protocol 1.0. The licences grant no rights to names or logos.
